# Next validation milestones

1. Independent numerical cross-comparison with exported spherical-lens reference datasets; strengthen pupil sampling to account for pupil aberration and energy weighting. Add finite-conjugate image analysis and sagittal/tangential field-curvature/ray-fan diagnostics.
2. Expand real manufacturer material records with sources; user-supplied material models and explicit substitutions; broader native project migrations and sensor state.
3. Global search and multiple starting designs only after evaluation remains stable across changing topology/apertures. Validate actual aperture and image-circle requirements independently.
4. Geometry/mechanical constraints, tolerance sensitivity and Monte Carlo with explicit assumptions.
5. Character metrics tied to measured aberrations, aperture-dependent targets, Pareto candidates, matched sets.

The large autonomous-design vision in the user brief remains future work. This increment delivers an integrated local optimizer for existing coaxial spherical systems; it is not an autonomous lens generator or a Zemax replacement.
