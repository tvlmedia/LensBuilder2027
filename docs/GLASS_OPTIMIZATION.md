# Verified glass selection and substitution

The existing catalog was audited for synthesis: only records with verified SCHOTT Sellmeier coefficients are eligible. This now includes **N-BK7, N-BK7HT, N-F2, N-LAK22, N-SK16, N-SF6, N-SF10, N-BAK4 and N-PK52A**, over the existing 400–700 nm analysis scope. The original broader nd/Vd table remains available to other explicitly approximate workflows, but is not silently used for synthesis. Manufacturer density, availability, transmission and cost data have not been added or invented.

The initial representative subset defaults to N-BK7 crown and N-F2 flint. The default retains these two materially distinct dispersion models for reproducibility. The **Use expanded verified glass set** button selects eight distinct models and enables deterministic glass-pair exploration. N-BK7HT has the same refractive model as N-BK7 in this catalog, and substituting between them is skipped as an optically duplicate proposal. New models use SCHOTT’s June 2025 AGF coefficients, retrieved 2026-09-29; exact source URL, archive SHA-256 and selected records are stored in [glass-catalog-provenance.json](glass-catalog-provenance.json). Manufacturer nd/Vd values are independently checked against indices computed from those coefficients. The analysis scope remains 400–700 nm. Previously approximate records for these six names now resolve to the verified model, including imported nd/Vd records. Older approximate analyses using those names should be rerun. No transmission or procurement properties are inferred.

`seedGlassPolicy: "sample-pairs-v1"` samples one crown (Vd > 50) and one flint (Vd < 50) per seed from the allowed list, with an independent deterministic random stream. Identical coefficient sets are deduplicated before sampling. Each seed still uses two glass types, preserving the maximum-unique constraint and Double Gauss symmetry. Missing policy or `first-pair-v1` keeps the original first-pair behavior; old N-BK7/N-F2 checkpoints remain numerically reproducible. A wider list spreads a fixed search budget across more alternatives and does not guarantee a better final lens.

Stages actually implemented (0.5.3):

1. Generate representative glass assignments with the topology's power roles and selected seed policy.
2. Optimize continuous geometry with those glasses fixed.
3. On a selected result, **OPTIMIZE GLASS** enumerates single-element substitutions and simultaneous replacements of every element using the same material. All proposals start from the frozen parent. Identical surface-set/material proposals are deduplicated; optically identical materials are skipped.
4. Whole-material replacements involving multiple elements adjust each nonzero-radius interface to preserve `(n_after - n_before) / R` at the d-line, including cemented interfaces. Zero-index-contrast degeneracies retain their radius. This is an initialization, not a claim of preserved aberrations. Single-element proposals retain the original radii. Both then recompute first order and uniformly scale to the target EFL, with full hard geometry/mechanics/material rejection.
5. Raytrace each physically admissible proposal and run up to 200 local geometry evaluations per substitution. Recompute clear apertures and densely validate every viable refined result; a coarse search score is not used to exclude a potentially better dense result.
6. Recompute the parent's dense score rather than trusting cached metadata. Retain a trial only when all hard checks pass and its dense merit strictly improves on the best accepted incumbent. Later trials cannot overwrite a better dense result merely because they improve the original parent or the coarse score.
7. Save affected surfaces, original/new glass, initialization, scale, search scores, dense score and acceptance/rejection status in the audit. Repeated operations append to `glassSearches`; `glassSearch` remains the latest audit.

This is an explicit additional operation, outside the original synthesis budget. More proposals mean additional work; 200 is a per-substitution local budget, not a global cap. Audit `evaluations` combines proposal/first-order attempts, objective evaluations and dense evaluations; `denseEvaluations` is also reported separately. Final aperture ray bundles are not counted as objective calls. The main synthesis run still does not launch this discrete stage automatically. A browser interruption restarts an additional pass from the saved parent; the final result is autosaved. Fixed glasses remain the default in Continue Search.

The final prescription's surface materials are authoritative. Original `synthesis.powers` metadata describes the generated seed, not later glass assignments. See the [measured family replacement comparison](GLASS_FAMILY_REFINEMENT.md).
